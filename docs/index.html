Firmware builder · Model:Cycles OS 1.13

Modded Cycles Techno Edition

Build the modded firmware right here in your browser, from your own copy of Elektron's official OS file. Nothing is uploaded anywhere: the file never leaves your computer.

Read the manual Manual (PDF) Source on GitHub Plug-in downloads m_reilly on SoundCloud

1Get the official OS

Download Model:Cycles OS 1.13 from elektron.se (Support › Downloads) and unzip it if needed. You need the file model-cycles_OS1.13.syx.

2Build the modded firmware

Download modded-cycles-techno-edition.syx

3Install it

  1. Back up your projects and samples with Elektron Transfer.
  2. Open Elektron Transfer, connect the Model:Cycles over USB and drop modded-cycles-techno-edition.syx on it, as for an official OS update.
  3. Wait until the Cycles restarts by itself (1–3 minutes). Do not switch it off during the update.

To go back, send Elektron's official OS 1.13 file the same way. Before that, set any track using an added machine (7–25) back to one of the six original machines, so your projects open cleanly on the stock OS.

Unofficial firmware. Tested in emulation against the Model:Cycles' own code and played on real hardware, but not made or supported by Elektron. Use it at your own risk. Only the main OS is changed: the bootloader and startup menu stay Elektron's, so the official OS can always be put back.
